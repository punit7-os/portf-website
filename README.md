## 🧪 Local Setup

### Clone Repository

git clone https://github.com/punit7-os/portf-website.git
cd portf-website

---

### Create Virtual Environment

python -m venv env
source env/bin/activate   # Linux/Mac
env\Scripts\activate      # Windows

pip install -r requirements.txt

python manage.py runserver
